Converter Reference

Quick reference

A compact guide to the text file the browser generates.

Every download is built locally and saved as filename-processed.txt. Text files are extracted in full. Images and other non-text files are summarized with metadata and byte previews so the output stays useful even when full text extraction is not practical.

Handling

How different files are handled

  • Text files are decoded and included in full. JSON is pretty-printed when possible.
  • Images are summarized with dimensions, aspect ratio, and a short byte preview.
  • PDFs and other binary files get metadata plus a byte and ASCII preview.
Notes

Practical tips

  • Drop one file at a time for the cleanest experience.
  • Clicking the main button uses the browser's native download flow.
  • The interface resets automatically after a successful download.
  • Nothing is uploaded to a server, so the workflow stays local.
